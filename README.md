# make.fun ghost — makefun-coin-launch-01 entry

This repository hands in a real pump.fun coin launched by an AI agent for
make.fun's "Race to launch a real coin on Solana" bounty ($1,000).

`LAUNCH.json` names the coin's mint address and the signature of the Solana
transaction that created it. `main.ts` copies `LAUNCH.json` to the output
directory when the entry is graded.
